# ﻿🎥WhatToWatch

A Movie Database in the form of a website, for searching and sorting any kind of movie, series, and much more. I built the website for learning purposes and for fun. The website is responsive and has other features / functionality.

# 💡Technologies
- **Backend:** Python, Flask
- **Database:** SQLite3
- **Frontend:** HTML5, CSS3
- **API:** TMDB (The Movie Database)

# ✨Features

Here's what you can do within **WhattoWatch**:

- **Advanced Search:** Use the search bar or filter by genres to find exactly what you want to watch across the entire database.
- **User Authentication:** Register or log in to a personal account to save your data.
- **Favorites & Watch Later:** Visit a movie's dedicated page to like it, add it to your favorites, or save it to your "Watch Later" list (requires a logged-in account).

# 🌍The Process

I started by creating the layout of the entire website with HTML, building the base with all the text and images. Then, i would go for CSS molding and focusing on design, making it more attractive and clean.

After some test and some redesign, next, i would go for starting coding in python with the library Flask, make a connection between the templates files with it, meanwhile, I also created an account to get the API key for the database(TMDB).

To make sure no one could get access to the API key i create a environment variable for more security. So, i got started building the backend for the search logic making sure i could connect to the database and get the data i want, using various functions for the job (redesign the website again for the movies be showed always on the right place).

Then, i focused on make the websites give me the inputs the user made and return the right output, organizing everything, like: The genre buttons, taken you to a new page where you could see countless pages with movies of that genre; The search bar, bringing movies with the keywords the user input, etc.

Before finishing the website i also made a Account system with Sqlite3, creating pages for you to login and register using a database to your username, email and your password and with your login, now you can save movies in your account by favorites, liked and watch later.
